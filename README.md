# 🦀 程序员工具箱

免费、开源的程序员在线工具箱，使用纯 HTML/CSS/JavaScript 构建，部署在 GitHub Pages 上。

## 🔧 功能

- 📋 JSON 格式化 — 压缩或美化 JSON，检查语法错误
- 🔐 Base64 编解码 — 文本与 Base64 互相转换
- ⏰ 时间戳转换 — Unix 时间戳与日期互转
- 🔗 URL 编解码 — URL 编码与解码
- 🔍 正则测试 — 在线测试正则表达式，高亮匹配
- 🔒 哈希计算 — MD5、SHA-1、SHA-256
- 🌍 IP 查询 — 查询 IP 归属地、运营商

## 🌐 在线使用

访问：https://as123456-prog.github.io

## 🛠️ 技术栈

- 纯前端（HTML/CSS/JavaScript）
- 暗色终端风格
- 本地存储（访问日志，密码保护）
- 免费部署在 GitHub Pages
